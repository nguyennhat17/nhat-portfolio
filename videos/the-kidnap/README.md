# The Kidnap videos

Suggested filenames:
- process-01.mp4: development or prototype footage
- inspiration-01.mp4: external mechanic inspiration
- gameplay-01.mp4: gameplay footage
- trailer.mp4: game trailer

Continue numbering for additional clips. Keep actual extensions if MKV or MOV; renaming an extension does not convert a video.
MP4 with H.264 video and AAC audio is preferred for browser playback. Originals can be checked and optimized before adding them to the page.
For source files over 100 MB, ask to prepare a web version and exclude the original from Git before committing.

Include short descriptions and source credits for inspiration clips when the files are ready.
