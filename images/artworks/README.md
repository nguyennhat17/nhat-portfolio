# Artworks upload guide

Still images go in stills/: artwork-01.png, artwork-02.png, etc.
Animated GIFs go in animations/: animation-01.gif, animation-02.gif, etc.
Use two-digit numbering in your preferred display order. Descriptive suffixes are optional, e.g. artwork-01-character.png or animation-01-walk-cycle.gif.
Preserve the actual extension; JPG and WebP stills are fine too. Upload the full-resolution export, not a website thumbnail. Keep transparent backgrounds if the asset needs them.

After adding files, tell me so I can connect them to the page. Files do not appear automatically.
Optionally add captions.md listing the filename, title, tool used, year, and a sentence about the exercise or intended game use. Mark studies based on references and include the source. Only list details you know.

The page will use still and animation galleries. GIFs retain animation when displayed as images. For long/large animations, we can prepare web-friendly video versions and playback controls after reviewing the files.
